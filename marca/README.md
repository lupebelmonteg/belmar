# Marca BELMAR

Logos oficiales que pasó Lupe (5/11/2026). La marca es **BELMAR** (nunca "BELMAR Studio").

## Color corporativo

- **Azul corporativo: `#101820`** (RGB 16, 24, 32), un azul marino casi negro. Es el fondo de los logos "fondo azul".
- Negro de las versiones "fondo negro": `#0B0C0C`.
- Blanco para el logo sobre fondos oscuros.
